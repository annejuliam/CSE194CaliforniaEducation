# FRPM school-level data

Source branch: `annejulia`  
File: `freeReducedLunch2526_FRPM_School-Level_Data.csv`

This is California Department of Education **Free or Reduced-Price Meal (FRPM)** eligibility at the school level for academic year 2025–2026.

## Important for the map

This CSV has **no latitude/longitude**, so schools cannot be plotted from it alone.
The old 19-school pilot location list was removed. To show schools on the map
again, add a coordinate source and join on the 14-digit CDS code
(`County Code` + `District Code` + `School Code`).
